# Sanity Studio for turesiliencia.com

Where the blog posts of https://turesiliencia.com are written. A standalone Sanity Studio (project `qnm95gjz`, dataset `production`), separate from the Astro site in the folder above: it has its own `package.json` and is neither built nor deployed with the site.

```bash
npm install
npm run dev      # Studio on http://localhost:3333
npm run deploy   # publish the hosted Studio
```
