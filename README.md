# turesiliencia.com

Personal site of Deissy Olarte, author of *Sobrevivir no es reconstruirse*: her blog and her book, in Spanish.

A static [Astro](https://astro.build) site deployed on Vercel. The blog posts are written in [Sanity](https://www.sanity.io): the Studio is in `studio/`, and the site reads the published posts when it builds.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
npm run preview  # serve the build
```

The Studio has its own commands: see `studio/README.md`.
