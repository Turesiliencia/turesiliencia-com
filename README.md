# turesiliencia.com

Personal site of Deissy Olarte, author of *Sobrevivir no es reconstruirse*. For now a single "coming soon" page in Spanish, while the new site is built.

Built with [Astro](https://astro.build) as a static site and deployed on Vercel.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
npm run preview  # serve the build
```
